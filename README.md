# 🎮 Ball VS Ball (BVB)

**Zagraj online:** https://shadow31905.github.io/ball-vs-ball/

## 🌐 1vs1 ze znajomym

1. Otwórzcie obaj link do gry w przeglądarce.
2. Pierwszy gracz: **Multiplayer online → Utwórz pokój**.
3. Kliknij **Kopiuj link dla znajomego** i wyślij go drugiemu graczowi.
4. Drugi gracz otwiera link i klika **Dołącz do pokoju**.
5. Po połączeniu pierwszy gracz klika **Rozpocznij 1vs1**.

Gracze mogą być w różnych sieciach Wi-Fi. Gra wykorzystuje **PeerJS + WebRTC** i domyślny serwer sygnalizacyjny PeerJS Cloud. Serwer ten nie przechowuje rozgrywki. Na niektórych sieciach połączenie może się nie udać (może być potrzebny TURN).
